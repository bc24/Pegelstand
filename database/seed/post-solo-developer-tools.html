Claude Code — mein KI-Entwicklungspartner

Seit ich Claude Code entdeckt habe, hat sich meine Arbeitsweise fundamental verändert. Claude Code ist das CLI-Tool von Anthropic — ein KI-Assistent, der direkt im Terminal läuft, meine Codebase liest, Dateien bearbeitet und Befehle ausführt.

Was mich begeistert: Es geht nicht darum, Code zu generieren und blind einzufügen. Ich arbeite im Dialog. Ich beschreibe, was ich will. Claude schlägt vor, erklärt die Entscheidungen, warnt vor Problemen. Ich entscheide. Es ist wie ein sehr fähiger Kollege — nur ohne Urlaubsansprüche.

Meine komplette neue persönliche Website wurde mit Claude Code entwickelt. Schnell, sauber, ohne Kompromisse bei der Qualität.

n8n — Automatisierung ohne Code-Zwang

n8n ist mein Schweizer Taschenmesser für Automatisierungen. Der Open-Source-Workflow-Builder läuft bei mir self-hosted auf dem VPS. Damit verbinde ich APIs, automatisiere Benachrichtigungen, verarbeite Webhooks und baue Prozesse, die früher Stunden manueller Arbeit bedeutet hätten.

Konkrete Beispiele aus meinem Alltag:

  • Automatische Produktwerbung über Telegram-Kanäle
  • Benachrichtigungen bei neuen Bestellungen in meinen Shops
  • Tägliche Zusammenfassungen von Statistiken aus verschiedenen Plattformen
  • Automatische Backups und Monitoring-Alerts

Telegram-Bots — direkter Draht zu meinen Nutzern

Ich betreibe mehrere Telegram-Bots für verschiedene Zwecke: Produktwerbung, Guten-Morgen-Nachrichten, Ruhezeiten-Verwaltung. Telegram ist für mich das beste Tool für direkte Kommunikation — schnell, zuverlässig, API-freundlich.

Die Bots baue ich mit PHP und der Telegram Bot API. Kein großes Framework, kein Overhead. Ein paar hundert Zeilen Code, und der Bot macht genau das, was er soll.

Raspberry Pi — physische Projekte

Nicht alles spielt sich im Browser ab. Für physische Maker-Projekte ist der Raspberry Pi mein Werkzeug der Wahl. Kleiner Rechner, großes Potenzial — vom Mediacenter über Heimautomatisierung bis zum selbst gebauten Webradio-Studio (in Planung).

Weitere Tools in meinem Stack

  • Linux / Debian — meine Server laufen alle auf Debian. Stabil, verständlich, kontrollierbar.
  • TeamViewer — Fernzugriff auf Kundenrechner für IT-Support. Schnell und zuverlässig.
  • GIMP / Photoshop — für alle Grafik-Arbeiten. GIMP für schnelle Sachen, Photoshop wenn's professionell sein muss.
  • VS Code + Claude Code — meine Entwicklungsumgebung. VS Code für die Übersicht, Claude Code für die Arbeit.
  • Plesk — für Kunden-Hosting-Management. Nicht schön, aber zuverlässig.

Das wichtigste Tool: Neugier

Am Ende sind Tools nur Werkzeuge. Was wirklich zählt, ist die Bereitschaft, neue Dinge auszuprobieren — auch wenn man nicht weiß, ob es funktioniert. Ich habe n8n entdeckt, weil ich ein Problem hatte und keine Lust auf eine Fertiglösung. Ich habe Claude Code entdeckt, weil ich neugierig war.

Das beste Tool ist das, das dein aktuelles Problem löst. Alles andere ist Rauschen.

Einfach anfangen. Der Rest kommt von selbst.
